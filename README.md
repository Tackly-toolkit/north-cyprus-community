# North Cyprus community platform

Free-to-start community for tourists and foreign residents of North Cyprus.

- `part1.html`, `part2.js`, `part3.js`, `scenes.js`: the app screens (built from the approved demo).
- `supabase/migrations/`: database setup (members, 3-month free period, 4-day payment window, invite-only switch, admin, areas, categories, banners switched off by default).
- `data/lists.json`: draft area and category lists, to be checked by Chris.

Secrets (database password, tokens) are never stored in this repository.
